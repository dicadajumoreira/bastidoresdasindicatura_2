# Dicadajumoreira — Site Ju Moreira

Site institucional de luxo da **Juliana Moreira** (Ju Moreira) — CEO da Sindicompany e da
Condo Academy, um dos principais nomes do mercado condominial brasileiro.

> **Sindicatura & Lifestyle** · @DicaDaJuMoreira

## Stack

Site estático, sem build step. Pode ser hospedado em qualquer lugar (Netlify, GitHub Pages,
Vercel, hospedagem simples) — basta servir a pasta.

```
dicadajumoreira/
  index.html      # página única (one-page)
  styles.css      # sistema visual de luxo
  assets/         # fotografias
```

## Rodar localmente

Abra `index.html` no navegador, ou sirva a pasta:

```
npx serve dicadajumoreira
```

## Seções

Hero · Sobre · Números (engajamento) · Na mídia · Palestras · Depoimentos · Público ·
Parcerias · Em cena (galeria) · Contato.
